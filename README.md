# IAM Joiner–Mover–Leaver (JML) Lifecycle Management

An Identity and Access Management (IAM) project demonstrating the employee identity lifecycle, including onboarding, job-role changes, access updates, and offboarding. It focuses on access provisioning and deprovisioning, role-based access control (RBAC), and secure identity lifecycle practices.

## Features

- Employee onboarding and identity creation workflow
- Employee role changes and access updates
- Employee offboarding and access revocation
- Joiner–Mover–Leaver (JML) lifecycle workflow representation
- Role-based access control (RBAC) concepts
- Access provisioning and deprovisioning scenarios
- Identity lifecycle documentation and workflow examples

## Project Workflow

### 1. Joiner — Employee Onboarding
- Represent the creation of an employee identity.
- Identify the access required for the employee's job role.
- Document the approval and access assignment process.

### 2. Mover — Employee Role Change
- Identify changes in department, job title, or responsibilities.
- Review existing access against the employee's new role.
- Document required access updates and removal of unnecessary permissions.

### 3. Leaver — Employee Offboarding
- Represent employee termination or departure.
- Document the removal or disabling of assigned access.
- Highlight timely access revocation to reduce unauthorized access risks.

## IAM Security Principles

- **Least Privilege:** Grant only the access needed for job responsibilities.
- **Role-Based Access Control:** Align permissions with defined job roles.
- **Access Governance:** Maintain appropriate approvals and access reviews.
- **Timely Deprovisioning:** Remove access when it is no longer required.
- **Auditability:** Document lifecycle activities for traceability and review.
